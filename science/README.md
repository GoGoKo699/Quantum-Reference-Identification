# Scientific reading route

The central question is whether a small physical reference library can be compiled into a classical record before an unknown query arrives. A retained quantum reference may still be tested against that query. A classical training record has already committed to a measurement.

Read these pages in order for the connected argument:

1. [Model and notation](model.md): the input distribution, timing boundary, success convention and charged resources.
2. [Finite-query quantum identification](quantum_identification.md): averaged projector hypotheses, achievable success, three-moment error converse and an explicit sequential decoder.
3. [Classical preprocessing](classical_preprocessing.md): arbitrary collective training, posterior moment bound, a covariant achieving strategy and the sharp fixed-copy asymptotic.
4. [Revealed-query endpoint](revealed_query.md): exact retained-quantum success when the later query is described classically.
5. [Implementation and resources](resources.md): a true Lüders symmetry test, finite-precision error and storage/gate costs.
6. [Regimes and interpretation](interpretation.md): what the comparison establishes, dimension requirements and limitations.

The [related-work account](../references/RELATED_WORK.md) distinguishes the multiclass consequence from inherited binary identification, Haar integration, state-estimation and discrimination tools. The [verification route](../verification/README.md) checks representative finite instances.

For a conceptual route, begin with the [worked three-qubit example](../learning/WALKTHROUGH.md), then use the [Watrous bridge](../learning/ANCHOR_AND_BRIDGE.md) and [30 milestones](../learning/MILESTONES.md).
